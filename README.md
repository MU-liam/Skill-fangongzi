# 爱情三十六计

版本 **4.8.3**。

这是一份可直接给 AI Agent 使用的 Skill。根据聊天截图、待发草稿或几句背景，帮助你做择偶定位、暧昧升温、聊天分析、长期相处、关系修复或去留决定，并直接给出当前判断和可执行的第一步。

## 使用方法

将本仓库根目录的 `SKILL.md` 与 `references/` 放到支持 Agent Skills 的环境中，然后发送一张聊天截图，或简单说明当前情况即可。若要进行对话对练，直接说「陪练」或「你扮演她」。

## 目录

- [`SKILL.md`](SKILL.md)：技能正文与各使用入口
- [`references/`](references/)：方法、场景、案例、长期相处与陪练等补充材料
