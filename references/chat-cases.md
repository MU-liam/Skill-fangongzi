# 聊天案例

## 校准案例

以下为合成案例。示例回复仅对应案例中已给出的事实。

| 聊天记录与目标 | 判断和可发送内容 | 下一步 |
|---|---|---|
| 对方「那家店的巴斯克真的好吃，下次想试抹茶的」。用户只想接话，自己试过别家抹茶巴斯克。 | 对方有具体可接的内容，单凭这句无需判断吸引程度。可回「我上次吃的抹茶巴斯克偏苦，反而还挺喜欢。你说的那家是哪家？」 | 看对方是否展开，发完等回复。 |
| 双方都在分享最近听的乐队，对方主动问用户有没有去过某家演出场地。用户去过一次，想见面，也知道那家周六有演出。 | 有共同话题，适合提一次明确邀请。「那家我去过一次。周六晚上有场演出，你想一起去吗？」 | 对方答应再确认时间。对方回「到时再说」且没给时间，先停在这。 |
| 对方「我觉得有点快，咱们慢一点吧。对了，你说那部电影叫什么？」 | 对方愿意继续聊天，也明确要求放慢。「好，咱们慢慢来。那部叫《片名》。」片名仅在用户确实提过这部电影时使用。 | 接下来聊电影，暂缓关系推进。 |
| 初识阶段互相开玩笑，用户说「你已经是我的电影搭子了」，对方回「才聊两天，是不是太快了哈哈」。 | 可以顺着玩笑回「这都不算啥呀，电影搭子还得挑到一部都想看的才算数😂」。如果想问清节奏，可以回「哈哈，我觉得这还不算快啊，你觉得哪一步快了？」 | 先看对方接不接梗。对方认真表示想慢点就接住，暂缓推进。 |
| 「周六不行，周日下午怎么样？」与「周六不行，最近都有点忙」 | 前者在协商时间，可回「周日下午我也有空，三点怎么样？」后者只能确认这次没约成，可回「好，等你有空想去再说。」 | 第一种继续确认。第二种先放下邀约。 |
| 对方「我只想当朋友」。 | 关系边界明确。「明白，谢谢你直接告诉我。」 | 停止追求。是否继续做朋友由用户真实意愿决定。 |
| 用户发了两条消息，截图只显示对方最后一句「哈哈」，后面没有时间信息。 | 只能说截图中没有新的接话点，无法判断对方是否冷淡或已经看到消息。建议先不发。 | 等对方回应。 |
# 热情表达与实际回应

合成对照。两个人都说「有空好想见你」。一方随后提出周日下午，另一方没有接续安排。前者可以确认时段，后者先观察有没有具体回复。消息里的热情、花费和安排兑现各有不同的参考价值。
