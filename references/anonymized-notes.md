# 匿名原稿整理

本页保留原有分析维度和实战思路。案例均为合成示例。

## 模型

| 分析维度 | 怎么用 |
|---|---|
| 初始吸引与展示面 | 先区分问题出现在见面前、初次见面，还是已有互动之后。用户提供资料时，检查照片、介绍和场景是否一致。 |
| 关系框架与互惠 | 看谁开话题、谁接话、谁在反复证明自己，双方是否都为下一步投入时间和精力。 |
| 由浅入深 | 从具体日常到感受，再到两个人都愿意谈的私人话题。话题深度随互动变化。 |
| 兴趣窗口 | 主动展开话题、提出替代时间和明确答应，对应不同的行动空间。单条短回、表情和慢回的权重低。 |
| 感觉与舒适度 | 看语气、内容和体验是否自然。一段互动可以舒服、有趣，同时停留在朋友层面。 |
| 共同体验 | 把想升温落实到一个双方感兴趣的活动。见面后的具体感受也可以成为下一轮交流的开头。 |
| 真实表达 | 说出具体经历、态度和感受，减少履历介绍、空泛赞美和连续提问。 |
| 复合与修复 | 看双方是否愿意重新互动、谈旧问题和讨论具体改变。过去的感情或亲密经历是背景，当前答复决定下一步。 |

## 启发式

- 初识时先分享一个容易接住的细节，给对方表达的空间。
- 有来有回时，用户想升温可以说一次具体的喜欢或期待，随后看对方是否也愿意展开。
- 有共同主题且想见面时，给出一项活动和一个时段。对方主动提出替代时间时继续确认。
- 话题一直由一方开启、另一方没展开时，先减少主动。可以用这一轮实际反馈决定何时收尾。
- 对方明确说慢一点或拒绝某步时，按对方给出的范围处理。用户依然可以对自己的沟通方式做具体复盘。

## 合成案例

- **初次见面后只聊客套话**。从两人实际聊过的一件事接起，补一句自己的感受，再看对方会不会接续。
- **见过几次，双方打趣，对方在意某个相处细节**。可以直接表达想再见，也把对方提过的细节接住。线下动作看当时答复。
- **分手后，一方重复解释，另一方说已经听过很多遍**。停止重复表态；如果对方之后主动提起一个具体矛盾，可以回应那件事，问对方愿不愿意继续聊。
